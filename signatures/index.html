Email signatures

One per brand. Type your phone number once, then press Copy and paste into Gmail.

Set them up in Gmail

  1. First, add each address as a "Send mail as" alias if you haven't: Gmail Settings (gear) > See all settings > Accounts > Send mail as > Add another email address. The alias must already exist in Google Workspace Admin (Users > Stephen > Alternate email addresses).
  2. Go to Settings > See all settings > General > Signature and press Create new. Name it after the brand (for example "Pours").
  3. Press Copy on that brand above, click into Gmail's signature box and paste (Ctrl/Cmd + V). The logo should show up in the box.
  4. Repeat for each brand.
  5. Under Signature defaults, pick each From address in the dropdown and set its signature for both new emails and reply/forward. Gmail then switches the signature automatically when you change the From address.
  6. Scroll down and press Save Changes. Send yourself a test from each address.

If the logo shows as a broken image, the site isn't live yet at distortedbrands.com. Paste anyway and re-paste once it's up. The Gmail phone app uses its own plain-text signature (app Settings > your account > Mobile signature).
